Official backend SDK for Jaza prepaid / metered billing.

```bash
npm install @jazadev/node
```

## Initialize

```ts
import { Jaza } from '@jazadev/node';

const jaza = new Jaza({
  secretKey: process.env.JAZA_SECRET_KEY!, // jz_test_sk_… or jz_live_sk_…
  publicKey: process.env.JAZA_PUBLIC_KEY!, // jz_test_pk_… or jz_live_pk_…
  // apiBaseUrl: 'http://localhost:3001', // local jaza-api only
});
```

Constructor is `{ secretKey, publicKey }` — not `{ apiKey }`.

## Methods

| Method | Description |
|--------|-------------|
| `createCustomer({ name, email?, phoneNumber? })` | Create customer; returns `cus_…` |
| `init({ customerId })` | Client session JWT + wallet/features snapshot for the mobile SDK |
| `consume({ customerId, featureCode \| credits, idempotencyKey })` | Debit wallet (server only) |
| `getBalance({ customerId })` | Wallet including `balanceCredits` |
| `topUp({ customerId })` | Top-up session + JWT (advanced / legacy BFF) |
| `check({ topUpId })` | Top-up session status |
| `webhooks.constructEvent(rawBody, signature, secret)` | Verify and parse merchant webhook payloads |

Errors throw `JazaError` with `statusCode`, `code`, and `raw`.

## Create a customer

```ts
const customer = await jaza.createCustomer({
  name: 'Amina Okello',
  email: 'amina@example.com',
});
// store customer.id on your user
```

## Mint a client session

```ts
const init = await jaza.init({ customerId: customer.id });
// return init from POST /api/jaza/init → JazaProvider getSession
```

See [Handshake](/guides/handshake).

## Consume credits

Prefer feature codes configured in the dashboard:

```ts
await jaza.consume({
  customerId: customer.id,
  featureCode: 'SEND_MESSAGE',
  idempotencyKey: `msg_${messageId}`,
});
```

Or debit a raw credit amount (do not send both `featureCode` and `credits`):

```ts
await jaza.consume({
  customerId: customer.id,
  credits: 10,
  idempotencyKey: `adj_${id}`,
});
```

## Webhooks

```ts
const event = jaza.webhooks.constructEvent(
  rawBody,
  req.headers['jaza-signature'],
  process.env.JAZA_WEBHOOK_SECRET!,
);
```

See [Webhooks](/guides/webhooks). Also exported: `constructEvent`, `WEBHOOK_EVENT_TYPES`.

## Read balance / advanced top-up

```ts
const wallet = await jaza.getBalance({ customerId: customer.id });

// Advanced: host-minted top-up JWT — prefer client session top-up in the RN SDK
const session = await jaza.topUp({ customerId: customer.id });
await jaza.check({ topUpId: session.id });
```
