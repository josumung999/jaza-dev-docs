Official React Native / Expo client for Jaza.

Use this in your **mobile app** with your publishable key (`jz_*_pk_*`) and a **client session** from your backend (`jaza.init` → `getSession` / `authEndpoint`). Never put your secret key in the app.

Server-side: [`@jazadev/node`](/sdks/node) — `init` for the handshake, `consume` for debits. The SDK mints short-lived top-up JWTs internally; apps do not implement `onRequestToken` on the happy path.

## Install

```bash
npm install @jazadev/react-native
```

Expo peers:

```bash
npx expo install react react-native react-native-reanimated react-native-gesture-handler react-native-safe-area-context react-native-screens @gorhom/bottom-sheet @expo/vector-icons @shopify/flash-list
```

## Expo config

    }
  }

## Provider setup

Wrap the app outermost with `GestureHandlerRootView`, then `JazaProvider`. Prefer `getSession` (or `authEndpoint`).

<Tabs>
  <Tab title="Expo Router">
    ```tsx
    import { Stack } from 'expo-router';
    import { GestureHandlerRootView } from 'react-native-gesture-handler';
    import { JazaProvider, type InitResult } from '@jazadev/react-native';

    const API_BASE = process.env.EXPO_PUBLIC_API_URL!;

    export default function RootLayout() {
      return (
        <GestureHandlerRootView style={{ flex: 1 }}>
          <JazaProvider
            publishableKey={process.env.EXPO_PUBLIC_JAZA_PUBLISHABLE_KEY!}
            getSession={async () => {
              const res = await fetch(`${API_BASE}/api/jaza/init`, {
                method: 'POST',
                credentials: 'include',
              });
              if (!res.ok) throw new Error('Jaza init failed');
              return (await res.json()) as InitResult;
            }}
            onAuthError={() => console.warn('Jaza session expired')}
            onTopUpComplete={({ credits }) => {
              console.log('Top-up completed', credits);
            }}
            theme="system"
            locale="en"
          >
            <Stack />
          </JazaProvider>
        </GestureHandlerRootView>
      );
    }
    ```
  </Tab>
  <Tab title="Classic App">
    ```tsx
    import { GestureHandlerRootView } from 'react-native-gesture-handler';
    import { JazaProvider, type InitResult } from '@jazadev/react-native';
    import { HomeScreen } from './screens/HomeScreen';

    export default function App() {
      return (
        <GestureHandlerRootView style={{ flex: 1 }}>
          <JazaProvider
            publishableKey={process.env.EXPO_PUBLIC_JAZA_PUBLISHABLE_KEY!}
            getSession={async () => {
              const res = await fetch(
                `${process.env.EXPO_PUBLIC_API_URL}/api/jaza/init`,
                { method: 'POST', credentials: 'include' },
              );
              if (!res.ok) throw new Error('Jaza init failed');
              return (await res.json()) as InitResult;
            }}
            theme="system"
          >
            <HomeScreen />
          </JazaProvider>
        </GestureHandlerRootView>
      );
    }
    ```
  </Tab>
</Tabs>

### Provider props (high level)

| Prop | Role |
| --- | --- |
| `publishableKey` | Required `jz_*_pk_*` |
| `getSession` | Preferred: return `InitResult` from your host |
| `authEndpoint` | Alternative: SDK POSTs this URL for `InitResult` |
| `getBalance` | Legacy-only balance callback |
| `theme` | `'light' \| 'dark' \| 'system'` |
| `locale` | `'en' \| 'fr' \| 'sw' \| 'ln'` |
| `onAuthError` | Handshake / session failure |
| `onTopUpComplete` | Payment succeeded |

See [Handshake](/guides/handshake).

## Balance — `JazaBalance`

```tsx
import { JazaBalance } from '@jazadev/react-native';

<JazaBalance />
```

`JazaBalanceWidget` remains as a deprecated alias.

## Top up — `JazaTopUpButton`

Opens the sheet using a session-minted top-up JWT (no `onRequestToken`).

```tsx
import { JazaBalance, JazaTopUpButton } from '@jazadev/react-native';

<JazaBalance />
<JazaTopUpButton label="Top up credits" />
```

## Ledger — `JazaLedger`

```tsx
<JazaLedger mode="preview" limit={5} />
<JazaLedger mode="scroll" />
```

`mode="scroll"` needs peer `@shopify/flash-list`.

## Gate — `JazaActionButton`

Gate only — never consume. See [Gating actions](/guides/gating-actions).

```tsx
<JazaActionButton
  featureCode="SEND_MESSAGE"
  label="Send message"
  onPress={async () => {
    await fetch(`${API}/api/messages`, { method: 'POST', credentials: 'include' });
  }}
/>
```

## What happens after Top up

1. SDK calls `POST /v1/client/top-ups` with the session token
2. Sheet opens → bundles and balance
3. User picks bundle → phone, country, currency → quote
4. Confirm → Jaza collects via Mobile Money → SDK polls
5. Balance refreshes via `GET /v1/client/wallet`

You do not configure MoMo aggregators; Jaza handles collection and settlements.
