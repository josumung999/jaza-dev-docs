This guide takes you from zero to a working prepaid flow using **Expo / React Native** and **Node.js**.

<Tip>
  Jaza collects Mobile Money and settles to you. You do not create a PawaPay account or manage multi-currency settlement yourself.
</Tip>

## Prerequisites

- A [Jaza](https://jaza.dev) developer account
- Node.js 18+
- An Expo app (Expo Router or classic `App.tsx`)
- Sandbox API keys from the [dashboard](https://jaza.dev/dashboard)

## 1. Create an app and copy keys

In the dashboard:

1. Create an app and enable **Countries** (Mobile Money markets)
2. Add at least one **feature** (e.g. `SEND_MESSAGE`) and one **bundle**
3. Open **API keys** and copy sandbox keys

| Key | Where it lives | Example prefix |
| --- | --- | --- |
| Secret | Server only (`JAZA_SECRET_KEY`) | `jz_test_sk_…` |
| Publishable | Mobile app (`EXPO_PUBLIC_JAZA_PUBLISHABLE_KEY`) | `jz_test_pk_…` |

<Warning>
  Never ship the secret key in a mobile binary or public repo.
</Warning>

## 2. Install the Node SDK

```bash
npm install @jazadev/node
```

Create a shared server client:

```ts
import { Jaza } from '@jazadev/node';

export const jaza = new Jaza({
  secretKey: process.env.JAZA_SECRET_KEY!, // jz_test_sk_…
  publicKey: process.env.JAZA_PUBLIC_KEY!, // jz_test_pk_…
});
```

## 3. Create a customer

Call once when your user signs up; store `customer.id` on your user record.

```ts
const customer = await jaza.createCustomer({
  name: 'Amina Okello',
  email: 'amina@example.com', // and/or phoneNumber
});

// persist customer.id → your DB
```

## 4. Expose a host init route

The mobile SDK needs a **client session** from your backend. Map the signed-in user → Jaza `customerId` → `jaza.init`.

```ts
// POST /api/jaza/init  (require your app session)
app.post('/api/jaza/init', async (req, res) => {
  const result = await jaza.init({
    customerId: req.user.jazaCustomerId,
  });
  res.json(result); // sessionToken + wallet/features snapshot
});
```

The app never calls Jaza with the secret key. It calls **your** BFF; you call the Node SDK.

See [Handshake](/guides/handshake) for `getSession` vs `authEndpoint` and 401 re-auth.

## 5. Install the React Native SDK

```bash
npm install @jazadev/react-native
```

Peer dependencies (Expo):

```bash
npx expo install react react-native react-native-reanimated react-native-gesture-handler react-native-safe-area-context react-native-screens @gorhom/bottom-sheet @expo/vector-icons @shopify/flash-list
```

Ensure Android resizes with the keyboard (`app.json`):

```json
{
  "expo": {
    "android": {
      "softwareKeyboardLayoutMode": "resize"
    }
  }
}
```

## 6. Wrap the app with `JazaProvider`

Pass `getSession` (preferred) so the SDK loads the client session from your init route. The SDK then talks to Jaza client APIs with the **session token** + **publishable key**. Top-up JWTs are minted internally — no host `onRequestToken`.

<Tabs>
  <Tab title="Expo Router">
    ```tsx
    // app/_layout.tsx
    import { Stack } from 'expo-router';
    import { GestureHandlerRootView } from 'react-native-gesture-handler';
    import { JazaProvider, type InitResult } from '@jazadev/react-native';

    const API_BASE = process.env.EXPO_PUBLIC_API_URL!;

    export default function RootLayout() {
      return (
        <GestureHandlerRootView style={{ flex: 1 }}>
          <JazaProvider
            publishableKey={process.env.EXPO_PUBLIC_JAZA_PUBLISHABLE_KEY!}
            getSession={async () => {
              const res = await fetch(`${API_BASE}/api/jaza/init`, {
                method: 'POST',
                credentials: 'include',
              });
              if (!res.ok) throw new Error('Jaza init failed');
              return (await res.json()) as InitResult;
            }}
            onAuthError={() => {
              console.warn('Jaza session expired');
            }}
            onTopUpComplete={({ credits }) => {
              console.log('Top-up completed', credits);
            }}
            theme="system"
            locale="en"
          >
            <Stack />
          </JazaProvider>
        </GestureHandlerRootView>
      );
    }
    ```
  </Tab>
  <Tab title="Classic App">
    ```tsx
    // App.tsx
    import { GestureHandlerRootView } from 'react-native-gesture-handler';
    import { JazaProvider, type InitResult } from '@jazadev/react-native';
    import { HomeScreen } from './screens/HomeScreen';

    export default function App() {
      return (
        <GestureHandlerRootView style={{ flex: 1 }}>
          <JazaProvider
            publishableKey={process.env.EXPO_PUBLIC_JAZA_PUBLISHABLE_KEY!}
            getSession={async () => {
              const res = await fetch(
                `${process.env.EXPO_PUBLIC_API_URL}/api/jaza/init`,
                { method: 'POST', credentials: 'include' },
              );
              if (!res.ok) throw new Error('Jaza init failed');
              return (await res.json()) as InitResult;
            }}
            theme="system"
          >
            <HomeScreen />
          </JazaProvider>
        </GestureHandlerRootView>
      );
    }
    ```

## 7. Balance, top-up, ledger, and gated actions

```tsx
import { View } from 'react-native';
import {
  JazaBalance,
  JazaTopUpButton,
  JazaLedger,
  JazaActionButton,
} from '@jazadev/react-native';

const API_BASE = process.env.EXPO_PUBLIC_API_URL!;

export default function HomeScreen() {
  return (
    <View style={{ padding: 20, gap: 16 }}>
      <JazaBalance />
      <JazaTopUpButton label="Top up credits" />
      <JazaLedger mode="preview" limit={5} />
      <JazaActionButton
        featureCode="SEND_MESSAGE"
        label="Send message"
        onPress={async () => {
          await fetch(`${API_BASE}/api/jaza/actions`, {
            method: 'POST',
            credentials: 'include',
            headers: { 'Content-Type': 'application/json' },
            body: JSON.stringify({ featureCode: 'SEND_MESSAGE' }),
          });
        }}
      />
    </View>
  );
}
```

- **`JazaBalance`** — credits from the session snapshot / client wallet refresh (`JazaBalanceWidget` is a deprecated alias)
- **`JazaTopUpButton`** — opens the MoMo sheet; SDK mints the top-up JWT from the session
- **`JazaLedger`** — recent movements (`preview` or `scroll`)
- **`JazaActionButton`** — **gate only**; opens top-up when balance is too low; never debits

## 8. Meter a feature on the host

`JazaActionButton` is UX. Real enforcement is always `jaza.consume` on your backend with the secret key.

```ts
// POST /api/jaza/actions  (or your feature route)
await jaza.consume({
  customerId: req.user.jazaCustomerId,
  featureCode: 'SEND_MESSAGE', // configured in the dashboard
  idempotencyKey: `msg_${messageId}`,
});
```

Use a stable `idempotencyKey` so retries do not double-charge. See [Consume credits](/guides/consume-credits) and [Gating actions](/guides/gating-actions).

## Optional: merchant webhooks

Register HTTPS endpoints under **App Settings → Webhooks**, then verify payloads with `jaza.webhooks.constructEvent`. See [Webhooks](/guides/webhooks).

## What you just shipped

- Client session handshake (no secret in the app)
- Credit wallet UI + MoMo top-ups without running an aggregator
- Feature gating in the UI and metering on your backend
