---
title: "POST /customers — Create a Jaza Customer"
sidebarTitle: "Create Customer"
description: "Create a new Jaza customer linked to your app user. Returns a cus_ ID and an empty wallet ready for top-ups."
---

Use this endpoint to create a Jaza customer that maps to one of your app users. Each customer receives a unique `cus_` ID and an empty credit wallet that can be topped up before you call `consume`.

## Endpoint

```text
POST /customers
```

## Headers

| Header | Value |
| --- | --- |
| `Authorization` | `Bearer <YOUR_SECRET_KEY>` |
| `Content-Type` | `application/json` |

## Request body

<ParamField body="externalId" type="string" required>
  Your app's own user identifier. Must be unique per app; Jaza rejects duplicates.
</ParamField>

<ParamField body="name" type="string" optional>
  The customer's display name (optional).
</ParamField>

<ParamField body="email" type="string" optional>
  The customer's email address (optional).
</ParamField>

## Response fields

<ResponseField name="id" type="string">
  The Jaza customer ID, prefixed with `cus_`.
</ResponseField>

<ResponseField name="externalId" type="string">
  The `externalId` you provided.
</ResponseField>

<ResponseField name="name" type="string | null">
  The display name, if provided.
</ResponseField>

<ResponseField name="email" type="string | null">
  The email address, if provided.
</ResponseField>

<ResponseField name="balance" type="integer">
  Wallet balance in credits. Always `0` immediately after creation.
</ResponseField>

<ResponseField name="createdAt" type="string">
  ISO 8601 timestamp when the customer was created.
</ResponseField>

## Examples

<CodeGroup>

```bash curl
curl -X POST https://api.jaza.dev/v1/customers \
  -H "Authorization: Bearer jz_test_sk_4eC39HqLyjWDarjtT1zdp7dc" \
  -H "Content-Type: application/json" \
  -d '{
    "externalId": "user_8923",
    "name": "Amina Bello",
    "email": "amina.bello@example.com"
  }'
```

```js Node
import { Jaza } from "@jazadev/node";

const jaza = new Jaza({ secretKey: process.env.JAZA_SECRET_KEY });

const customer = await jaza.customers.create({
  externalId: "user_8923",
  name: "Amina Bello",
  email: "amina.bello@example.com",
});

console.log(customer.id); // cus_...
```

</CodeGroup>

Example response:

```json
{
  "id": "cus_9xY7zW2vQpLk",
  "externalId": "user_8923",
  "name": "Amina Bello",
  "email": "amina.bello@example.com",
  "balance": 0,
  "createdAt": "2026-08-01T09:15:30.000Z"
}
```

<Note>
  `externalId` must be unique per app. If you try to create a second customer with the same `externalId`, Jaza returns a `409 CONFLICT` error.
</Note>
