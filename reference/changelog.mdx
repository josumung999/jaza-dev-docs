This changelog tracks Jaza releases starting with the earliest milestones and moving forward. New entries appear at the top so you can see the latest changes first.

## August 23, 2026 – Developer Dashboard: Users & History

The Jaza Dashboard shipped three new views:

- **App overview** with a last-5 preview of recent credit activity.
- **Paginated credit activity** and **top-ups** with search and filters so you can audit any wallet movement quickly.
- **Users table** showing each customer’s current balance, lifetime credits purchased, and lifetime credits consumed.

## August 22, 2026 – React Native SDK \+ Sample App

`@jazadev/react-native` is now available with:

- `FuelBalance` widget for real-time balance display.
- Top-up bottom sheet with M-Pesa-style checkout UI.
- An Expo example app for local development and testing.

## August 20, 2026 – Node SDK \+ Customer Model

`@jazadev/node` shipped with the foundational merchant API for prepaid wallets:

- `createCustomer` – returns a short `cus_` ID.
- `topUp` – returns a JWT checkout token.
- `getBalance` – fetches the current wallet balance.

## August 18, 2026 – Mobile Money Checkout Rails

PawaPay integration went live. This release introduced:

- Bundle-based top-ups so customers buy preset credit packs.
- Integer local amounts for KES, CDF, and other non-USD currencies.

## July 29, 2026 – jaza.dev Is Live

The [jaza.dev](https://jaza.dev) landing page launched, along with the early-access waitlist.

## July 28, 2026 – Product Thesis Locked

Jaza’s direction was set as **pay-as-you-go fuel wallets for African apps**. The core primitives (credit wallets, Mobile Money and card top-ups, and an immutable ledger) were defined.
