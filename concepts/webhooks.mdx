Each app can register **multiple HTTPS webhook endpoints** (URL, signing secret, enabled events, status) under **App Settings → Webhooks**.

## What you get

- Signed POSTs with `Jaza-Signature`
- Top-up and consumption event types
- Dashboard delivery history, retries, and dead-letter visibility
- Verification via `jaza.webhooks.constructEvent` in `@jazadev/node`

Provider webhooks (for example PawaPay → Jaza) stay **inside** Jaza — you do not implement aggregator callbacks.

## Prefer the full guide

See **[Merchant webhooks](/guides/webhooks)** for setup, event catalog, signature verification, and Node samples.

For in-app balance after checkout, use the React Native sheet + `onTopUpComplete` / client wallet refresh. Treat merchant webhooks as complementary server automation.
